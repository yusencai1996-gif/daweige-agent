# 内部通报写作套路

## 第一步:接稿先盘三样

1. **领导要点**:给到的要点逐条编号——成稿后每一条都必须能对上,漏一条就是事故
2. **数字口径**:稿里的数字从账房核对结果或用户给的素材里来,**一个都不许编**;数字对不上就停下来问,不带病成稿
3. **读者是谁**:单位内部(同事/上级)——文风克制、信息密度高,不写对外宣传腔

## 第二步:三段式骨架(内部通报的标准结构)

1. **开头一段**:直接给结论(干了什么、结果如何),不超过三行
2. **中间主体**:数据支撑+工作亮点——按要点组织(一个要点一段),数字紧跟事实,每段只说一件事
3. **结尾展望**:下一步干什么、目标是什么(有对标数字就给对标,如"对标上月、下月冲多少")

## 第三步:行文规矩

- 句子短,多用具体名词和数字,少用形容词;**不堆"赋能""抓手""闭环"这类空词**
- 领导的原话精神保留原味,可以顺句子但不改意思
- 数据表述统一格式(金额千分位、百分比保留一位小数、前后口径一致)

## 第四步:交稿自检(交稿前逐条过)

- [ ] 领导要点逐条覆盖(对着第一步骤的编号清单核一遍)
- [ ] 稿里每个数字都能说出出处
- [ ] 三段结构完整,开头有结论、结尾有去向
- [ ] 通读一遍:有没有翻译腔、空话、重复表述

## 不要做

- 不编造任何数字、人名、事件
- 不替领导表态("下一步我们将…"只在用户素材里有依据时写)
- 给人看的成稿默认存 .docx;.md 只用于 agent 间交接或规则记录,不作为交付用户的成稿格式;文件名先给建议再存
