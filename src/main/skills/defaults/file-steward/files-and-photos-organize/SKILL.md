# 文件夹整理套路

## 第一步:摸底

1. 列出全部文件:数量、类型分布(照片/表格/文档/压缩包/其他)、大小
2. **先提方案再动手**:把分类规则和目标结构写给用户看一眼(尤其要挪位/改名的),确认了再批量执行——小批量(十个以内)可以直接动手,边干边报

## 第二步:照片归档

1. 归档粒度默认**按月**(YYYY-MM 文件夹);同一月照片少(≤5 张)可按季/年合并,说明即可
2. 日期从哪来:优先文件名里的日期 → 其次照片拍摄信息 → 都没有用文件修改时间,并在报告里注明来源
3. 重名冲突:加序号后缀(-01/-02),不覆盖任何文件

## 第三步:文档表格分类

1. 类型分桶:表格(xlsx/csv)/ 文档(doc/docx/pdf/md)/ 图片 / 其他——"其他"必须列明细,不许有文件去向不明
2. 命名规范默认:`日期前缀-原始名`(如 2026-08-销售表.xlsx);用户有自己的规范就按用户的
3. **待定文件**(看不出是什么的):单独放"待确认"文件夹,报告里列出让人看一眼

## 第四步:整理报告(干完必交)

```
一、动了什么:移动/改名各多少个,从哪到哪(表格列出前后对照)
二、没动什么:哪些文件原地没动、为什么
三、待确认:看不准的文件清单,等用户拿主意
```

## 不要做

- **任何删除动作必须单独确认**(整理不等于清理;发现疑似垃圾只报告,不删)
- 不覆盖同名文件(加序号)
- 不改变文件内容,只动位置和名字
- 挪动前记录原始路径——用户要后悔时能还原
