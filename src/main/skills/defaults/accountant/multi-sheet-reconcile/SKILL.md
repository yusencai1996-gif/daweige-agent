# 多表核对与汇总套路

## 第一步:摸底(动手算之前必做)

1. 每张表先读预览,记录:列结构、日期范围、金额列、有没有特殊行(合计行/备注行/空行)
2. **列序不同的表不假设对应**——逐列确认"哪列是什么",不同表的"销售额"可能不在同一列
3. 记下每张表的行数,后面核对时用得上

## 第二步:抓异常(这些不查,总数必错)

逐表过一遍这张检查单:

- [ ] **负数**:金额列里的负数通常是退款/冲销——单独列出,不能当普通数字求和(净额口径:销售 − 退款)
- [ ] **跨期混入**:日期列里有没有不属于目标期间的行(如 8 月表里混着 7 月的单)——剔除,并报告"剔了哪几笔"
- [ ] **新店/新科目**:半路开业的(如月中开业的门店、季度中新加的项目)——它的"环比"没有完整上月基数,单独说明
- [ ] **重复行**:完全相同的行可能出现两次——先问是不是重复录入,拿不准就报告不擅自删
- [ ] **单位混杂**:万元/元、含税/不含税——发现就报告,不默默换算

## 第三步:算数

1. 自己把数字算好再写结论,每个汇总数能追溯到"哪张表哪几行"
2. 结果同时给**总额和明细**:每张表的小计 + 合计,明细在前总额在后
3. 涉及环比/同比的,写清基数是什么(如"环比 7 月的 18000")

## 第四步:出报告(固定结构)

```
一、核对发现(异常清单:负数/跨期/新店/重复,每条带来源"某表第 N 行")
二、汇总结果(净额口径,分表小计+合计)
三、口径说明(含哪些、不含哪些、剔了什么)
```

## 不要做

- 不给没有依据的估算数;哪笔拿不准就单列出来问,不凑数
- 不改用户原始表格;结果另存新文件或另起列
- 异常不报告直接"顺手处理"——发现什么说什么,处理方式让用户定
